# RoutineNotify — Schedule Backup

RoutineNotify is a [desktop app](https://github.com/kurojs/RoutineNotify) that announces your daily schedule with AI voice and custom sounds.

This backup contains the **PLAN 2026** daily schedule (11 routines) with AI notifications enabled and the custom `regular_show_intro.ogg` sound embedded.

## Import

1. Download the app: [kurojs/RoutineNotify — Releases](https://github.com/kurojs/RoutineNotify/releases)
2. Open **Settings → Import backup** and select `routine-notify.json`
3. Each routine fires at its time with AI voice + the custom sound
